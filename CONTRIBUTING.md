# Contributing to MKV Subtitle Translator / Contribuindo para o Tradutor de Legendas MKV

[Português](#português) | [English](#english)

---

<a name="português"></a>
## 🇧🇷 Português

Obrigado por seu interesse em contribuir! Este projeto visa facilitar a vida de quem precisa traduzir legendas de forma rápida e eficiente.

### Como posso contribuir?

#### 1. Relatando Bugs
- Verifique se o bug já não foi relatado nas [Issues](https://github.com/fabiosilva974/SUB_Extract_Translate/issues).
- Se não encontrar, abra uma nova issue descrevendo o problema, o sistema operacional que está usando e, se possível, anexe um log ou exemplo da legenda que causou o erro.

#### 2. Sugerindo Melhorias
- Ideias para novos motores de tradução ou suporte a novos formatos são sempre bem-vindas!
- Abra uma issue com a tag `enhancement`.

#### 3. Enviando Pull Requests
- Faça um **Fork** do repositório.
- Crie uma branch para sua modificação (`git checkout -b feature/nova-funcionalidade`).
- Mantenha o estilo de codificação (PEP 8 para Python).
- Comente seu código em português ou inglês.
- Certifique-se de que a documentação foi atualizada se necessário.
- Envie o **Pull Request**!

<a name="english"></a>
## 🇺🇸 English

Thank you for your interest in contributing! This project aims to make life easier for those who need to translate subtitles quickly and efficiently.

### How can I contribute?

#### 1. Reporting Bugs
- Check if the bug has already been reported in the [Issues](https://github.com/fabiosilva974/SUB_Extract_Translate/issues).
- If not found, open a new issue describing the problem, the operating system you are using, and if possible, attach a log or example of the subtitle that caused the error.

#### 2. Suggesting Enhancements
- Ideas for new translation engines or support for new formats are always welcome!
- Open an issue with the `enhancement` tag.

#### 3. Submitting Pull Requests
- **Fork** the repository.
- Create a branch for your modification (`git checkout -b feature/new-feature`).
- Maintain the coding style (PEP 8 for Python).
- Comment your code in Portuguese or English.
- Ensure the documentation is updated if necessary.
- Submit the **Pull Request**!
